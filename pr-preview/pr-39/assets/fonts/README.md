# Self-hosted fonts

This site self-hosts three variable font families so that no third-party font
service is contacted at runtime.

| File | Family | License |
|------|--------|---------|
| `cormorant-garamond-500.woff2` | Cormorant Garamond (display) | SIL Open Font License 1.1, see `OFL-CormorantGaramond.txt` |
| `source-serif-4-400.woff2` | Source Serif 4 (body) | SIL Open Font License 1.1, see `OFL-SourceSerif4.txt` |
| `outfit-400.woff2` | Outfit (interface) | SIL Open Font License 1.1, see `OFL-Outfit.txt` |

The `.woff2` files are the Latin subsets downloaded from Google Fonts. The
license texts are the upstream SIL Open Font License files. Keep the license
files with the font binaries when copying or redistributing them.
